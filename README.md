## 💡 METODOLOGIA

O curso adota uma abordagem **Hands-on** (mão na massa), combinando teoria e prática imediata:
* **Teoria:** Aulas expositivas com suporte de slides.
* **Prática:** Uso intensivo de *Jupyter Notebooks* para experimentação de código.
* **Desafios:** Problemas reais do cotidiano médico/estatístico para fixação de conteúdo ao final de cada aula.
